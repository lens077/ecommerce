# Agent skills：采用状态

本页只记一类**不易过期**的信息：某 skill **是否采用**（决定入口文件能不能要求执行它）。
不记「已装 / 缺失」与版本号——它们是运行态，写入当天就开始过期；需要现况就跑 `command -v`。

列契约：第 1 列是 skill 名（反引号包裹），第 2 列是状态词。出现「缺失 / 不采用 / 未装」即视为不可用，
入口文档（`AGENTS.md`）不得要求执行它。改表时不要动这两列的位置。

## Skills

| Skill | 采用状态 | 用途 |
|---|---|---|
| `tech-doc-style` | 采用 | 中文技术文档写作风格 |
| `adr-writer` | 不采用 | 决策记录手写，模板见 `context/decisions/` |

安装与恢复动作写在项目自己的 runbook 里；本页不记录安装位置。
