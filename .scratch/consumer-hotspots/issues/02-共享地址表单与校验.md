# 共享地址表单与校验

Status: done

依赖：01，以及共用 useAddresses Promise 接口。

## 实现

地址簿和结算弹窗共用 `components/address/AddressForm.tsx`、`addressValidation.ts` 与 RegionSelect。helper 不使用仅大小写不同的文件名，避免 macOS 模块解析冲突。

字段限制按地址 proto，用 Unicode code point 计长，不新增国家手机号正则。districtRequired 为 true/false/null：有区县必填，无区县可空，当前省市未解析或请求失败阻止提交并显示重试。切换城市、切换编辑地址不沿用旧区县状态。

表单统一使用 addresses.form 命名空间；采用 DESIGN.md 要求的 lantern surface，不混用旧配色。设默认选项仅用于创建，编辑页通过独立 SetDefaultAddress 操作。

## 验收标准

1. `addressValidation.test.ts` 覆盖空区县、未解析区划、长度和空白必填校验并通过。

4. consumer 类型检查、a11y 与完整 pnpm ready rc=0。
