# 结算页地址选择与提交

Status: done

依赖：01、02 与共用 Promise hook。

## 实现

路由仅注册 CheckoutPage；页面与 AddressPickerDialog 分离。地址列表使用 RadioGroup/FormControlLabel，不嵌套 button 和 input；新增失败保留输入，成功按响应 ID 自动选中。

下单不再过滤条目：选中项必须有合法正 int64 ID，存在于成功服务端快照，数量、单价、SKU/SPU/商家与快照一致，且选中地址仍在列表。查询刷新/错误时不使用未证明的缓存提交。本地改数量尚未持久化时明确阻断，避免显示 3 件却创建 2 件订单。单页 ref 防重复点击不等于后端幂等，requestId 与固定支付跳转仍属其他任务。

本次改造的 surface 使用 lantern token。真实移动端截图发现 copilot 闭合悬浮钮遮挡保存按钮，已将闭合入口降到 modal 以下，不改展开面板行为。
