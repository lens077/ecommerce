Connect-RPC / protobuf 接口（api/*/v1）只允许 service（proto ⇄ biz 转换）与 server（注册 *v1connect handler）导入
service：handler 与协议转换proto ⇄ biz 模型；领域错误映射为 RPC 错误码；不越层直连 data
biz：领域模型 · 用例 · Repo 接口定义不导入 data / service / server，不认识 api/*/v1、connect、存储驱动与第三方 SDK；可直接接收 conf/v1 配置 schema
data：实现 biz 的 Repo 接口 · sqlc · 迁移 · 第三方 SDK 封装不导入 connect 与 api/*/v1；返回领域错误，由 service 映射 RPC 码
