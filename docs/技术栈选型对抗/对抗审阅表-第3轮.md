### R3-A casdoor 收编迁移（主设计 claude2 · 红队 codex）——**通过 + 3 补丁**

- 设计主轴获认可：**公网 origin `casdoor.apikv.com` 不变** ⇒ iss/redirect/cookie 全不变 ⇒ 前端三 app + 桌面零改动、存量 token 与 `prompt=none` 静默续期存活；kid=lens 签名证书随 DB 迁移、网关 `secrets/public.pem` 同字节不动——**「全员重登」分支被设计消除**。P0 查证（DB 引擎分支/redirect 白名单/arm64 双架构镜像已核实、同版本迁移禁升级）→ P1 集群就绪（`Database` CR + JWKS `diff==0` 门禁）→ P2 切流（写冻结→终版 dump→Pangolin 路由切 newt，停机 ≤30min，回退=路由切回+旧容器 start 分钟级，24h 回退窗内新注册丢失已明示）→ P3 收内（仅 user-service endpoint 一处改动 + TODO L32 CA 遮蔽坑规避）+ 8 项验收。
- 红队命中情况：codex 10 项必查中 8 项设计已覆盖；**双方独立发现 desktop 第 4 客户端**（设计 P0 白名单与验收①均含 Tauri loopback，收敛佐证）；Top3（公钥不连续/回调环/终版增量丢失）分别被 diff==0 门禁、origin 不变、写冻结+小库全量 dump 消解。

### R3-C CI 供应链实施稿（主设计 codex · 红队 claude2）——**通过 + 6 补丁**

- 设计获认可：嵌入现有 `backend.yml`/`service-ci.yml`（detect 后加 security job；矩阵与 update-manifests 保留）；gitleaks+Trivy fs 全仓门禁（HIGH/CRITICAL 阻断+豁免流程）；对 `TCR@digest` 做 Trivy image+Syft SPDX+cosign 签名+attest，失败不回写；**签名选型裁决：key-based 仅强制 TCR**（LAN 未验通→Rekor 故弃 keyless，policy 显式 `rekor.ignoreTlog:true`，不暗关；GHCR 非集群拉取源暂不签）——**该裁决同时被红队独立支持**（其 Top3③正是 keyless 公网依赖）；helm library 加 `image.digest` 优先渲染；update-manifests `crane digest`+`cosign verify` 后回写 tag+digest；Kyverno 专用 SA+只匹配业务 TCR、audit→enforce、`PolicyException` 带 ns+digest+事故号+到期；全部 action 按 40 位 SHA 固定+shell 门禁。
