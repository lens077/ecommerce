## P1 · consumer（SPA）

- [ ] **cart 删除/改数量前端未接线**：后端 `RemoveCartItem`/`UpdateCartItemQuantity` 均已实现，
      前端 `useCart` 的 `removeItem`/`updateQuantity` **只动本地 store 不发请求**——
      **用户删掉商品后刷新页面它会回来**（`GetCart` 拉的还是旧数据，同步 effect 会 clear 再灌回去），
      即这两个功能对用户实际不存在。
      修法：两个 hook 各接 `useMutation` + `invalidateQueries`，模式与现有 `addProductToCart` 同构。
