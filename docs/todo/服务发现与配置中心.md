      且其 PDB `maxUnavailable=0` 导致**既不能挂也不能安全驱逐**。
      要么扩为 3 副本，要么明确接受单点并调整 PDB。

- [ ] **Consul 启用 TLS**：当前 8501/HTTPS 不存在、gossip 未加密，
      但 prod 清单仍写 `https://consul-server.consul.svc:8501`（见

- [ ] **十服务 Config Center 单源迁移收尾**：仓库侧已完成、pre 直发验收已通过，
      **GitOps 尚未闭环**。
      〔实测 2026-08-31〕线上业务服务仍读取 dev，control-tower gateway 单独读取 pre；
      两类消费方均已迁移到独立 Machine Token，每枚 token 只允许对应
      environment×namespace。仓库同时加固了尚未应用的 prod 裸清单和 pre Helm 路径，
