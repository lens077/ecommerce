## 门禁约束备忘（改文档前必读）

`scripts/verify-context.sh` 是 main 上唯一必需的 CI 检查，任一违规 → 退出码 1：

| 检查 | 范围 | 易踩的坑 |
|---|---|---|
| `[DEAD-LINK]` | **仅** `AGENTS.md` `README.md` `STACK.md` `context/**` `docs/design/**` | `docs/` 顶层与 reports/archive 的死链**抓不到**；目标被 `.gitignore` 命中也算死链 |
| `[ORPHAN]` | 仅 `context/` 树 | 新增/改名/移动 `context/` 下任何 md 都要同步改对应 INDEX |
| `[FRONTMATTER]` | `context/**`（除 INDEX） | `name:` 必须等于文件名；跨层移动要改 `layer:`/`module:` |
| `[FORMAT]` | `context/**/experience/*.md` | 必须含「症状」+「关键陷阱/陷阱」小节；基线棘轮会反向要求删除已合规的基线行 |
| `[EVOLOG]` | `evolution-log.md` | 每个 `### ` 块必须四要素齐全 |
| `[BUDGET]` | `AGENTS.md` ≤14000 B / `TODO.md` ≤96000 B | **AGENTS.md 余量极小**，补充说明应写进 `context/` 而非 AGENTS.md |

⚠️ 改 harness 本身（硬规则、门禁脚本、structcheck、CI 门禁）必须在
[`evolution-log.md`](../../context/harness-framework/evolution-log.md) 追加四要素记录。
