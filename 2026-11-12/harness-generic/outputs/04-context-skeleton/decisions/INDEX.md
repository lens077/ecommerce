# decisions/ — 决策记录

## 写法（三条硬约束）

1. **路径即状态**：`decisions/<topic>.md` 存在 = 该决策仍生效；被推翻就**删除文件**，不写「已废弃」。
   删除动作本身进入 git 历史，比一份没人读的废弃列表可靠。
2. **必须写「考虑过的替代方案」**——只说选了什么、不说否了什么，半年后没人能判断该不该改。
3. **一条决策一个文件**，文件名即主题，不按日期编号。
